## Research discipline

CARS separates scientific objects, measurement structures, estimators, execution substrates, and interpretation boundaries.

Core rules:

```text
error signals failure, not cause
validated consequence grants local authority only
measurement can partly constitute the scientific object
minimal sufficient revision > post-hoc rescue
null / negative results are informative
stop escalation once the frozen question is answered
```

A benchmark is not allowed to inherit the conclusion it is meant to establish.
