# Intelligence Theory — Functional Conjecture

## Status

```text
THEORY
→ CONJECTURE

MECHANISM
→ UNSPECIFIED

SPECIAL ARCHITECTURE
→ NONE REQUIRED / NONE ESTABLISHED

CURRENT EMPIRICAL SUPPORT
→ NOT ESTABLISHED
```

## Core conjecture

> **Intelligence is the capacity of a system to convert appropriately informative new evidence into increased expected future viability.**

Compact shorthand:

```text
I_t ∝ Δ_E[V_{t+h}]
```

The proportionality symbol is **theoretical shorthand**, not a claimed linear law. The scientifically meaningful commitment is weaker:

```text
greater evidence-mediated expected future-viability gain
→ greater intelligence under the conjecture
```

The conjecture therefore permits nonlinearities, saturation, thresholds, horizon dependence, context dependence, and heterogeneous evidence value.

## Evidence use, not evidence presence

The intended causal path is:

```text
informative evidence E
        ↓
system-mediated update
        ↓
state / policy / representation / memory change
        ↓
changed future trajectory
        ↓
changed expected viability V_{t+h}
```

Evidence does not count merely because it is present or correlated with a better future. The relevant quantity is the future-viability gain attributable to the system's **use** of evidence.

A useful conceptual notation is:

```text
Δ_E^use V_{t+h}
```

meaning the counterfactual expected future-viability difference attributable to evidence-mediated adaptation. This notation does not yet define an identified causal estimand; causal mediation remains an empirical burden.

## Frozen non-equivalences

```text
current performance
≠ intelligence

learning speed
≠ intelligence

behavioral change
≠ intelligence

prediction accuracy
≠ intelligence

evidence responsiveness
≠ viability gain

viability gain without evidence mediation
≠ evidence-conversion intelligence
```

A system may therefore have high current capability but low evidence-conversion capacity, or low initial capability but high evidence-conversion capacity.

## Functional, not architectural

The theory does **not** propose a special intelligence component.

Its implementation may be entirely ordinary:

```text
state
information
observation
representation
memory
learning
policy
control
dynamics
```

Accordingly:

```text
no correction controller
↛ theory false

no special predictive state
↛ theory false

no adaptive-specific complexity burden
↛ theory false

ordinary mechanisms suffice
↛ theory false
```

The theory is a claim about a functional relation across trajectories, not a claim about a unique architectural primitive.

## Empirical burden hierarchy

```text
THEORY
Intelligence concerns evidence → future viability
        │
        ▼
FORECASTABILITY
Can present state predict future response to unseen evidence/tasks?
        │
        ▼
PREDICTIVE STRUCTURE
What ordinary state variables explain that response?
        │
        ▼
RESOURCE QUESTION
How much representation / computation / data is required?
        │
        ▼
ADAPTATION
Is the response actually evidence-mediated system change?
        │
        ▼
VIABILITY
Does the change improve future outcomes under a prospectively defined V?
        │
        ▼
CAUSAL MEDIATION
Is the gain attributable to the system's use of evidence?
        │
        ▼
CONSTRUCT VALIDITY
Does this relation explain what independent theories/measures call intelligence?
```

Each arrow is a separate empirical burden.

## Current benchmark relation

The frozen future-plasticity benchmark tests only a substrate-level question:

```text
S_t → Γ_t(E*)
```

where `Γ_t(E*)` is a future learning trajectory on a concealed future task transformation.

A positive result would establish forecastability within that benchmark at most. It would not establish viability gain, causal evidence use, or intelligence.

A negative result would localize failure to that measurement/benchmark route. It would not by itself falsify the intelligence conjecture.

## Construct-validity burden

Even if `Δ_E^use V_{t+h}` becomes measurable, predictable, and causally identifiable, that does not automatically justify calling it intelligence.

Keep separate:

```text
EMPIRICAL EXISTENCE
Does evidence-mediated viability conversion vary systematically and measurably?

CONSTRUCT VALIDITY
Does that variation capture something central enough to justify identifying it with intelligence?
```

The current program has not reached the second burden.

## Governing rule

> **The theory specifies what may matter. The empirical program gives ordinary machinery every opportunity to explain it away. Only what survives that subtraction earns additional scientific structure.**
