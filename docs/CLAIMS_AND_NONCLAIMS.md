# Claims and Non-Claims

## Repository-level claim structure

The repository now contains distinct layers that must not borrow authority from one another:

```text
1. a functional intelligence conjecture;
2. an epistemic control protocol (CARS);
3. closed empirical/synthetic lineages that constrain stronger interpretations;
4. a frozen independent future-plasticity forecast benchmark with no scientific result yet;
5. ASI-0, a frozen causal-attribution skeleton for evidence-to-target assignment with no scientific result yet.
```

None of these artifacts acquire empirical authority merely because they are mutually coherent.

## Intelligence theory — current status

Canonical theory:

- [`INTELLIGENCE_THEORY.md`](INTELLIGENCE_THEORY.md)

Conjecture:

> **Intelligence is the capacity of a system to convert appropriately informative new evidence into increased expected future viability.**

Shorthand:

```text
I_t ∝ Δ_E[V_{t+h}]
```

The shorthand is not a claimed linear law. The substantive theoretical commitment is only:

```text
greater evidence-mediated expected future-viability gain
→ greater intelligence under the conjecture
```

Current status:

```text
THEORY
→ CONJECTURE

MECHANISM
→ UNSPECIFIED

CURRENT EMPIRICAL SUPPORT
→ NOT ESTABLISHED
```

## CARS control protocol

```text
CARS control protocol
≠ intelligence theory
≠ empirical benchmark
```

CARS governs how evidence is localized, authority is assigned, revisions are made, and stopping occurs.

The theory states a conjectured functional relation. Experiments test scoped empirical propositions. None validates the others automatically.

### No current ASI-0 positive claim

The repository does **not** currently establish that correctly aligned development evidence improves a real agent. The canonical model/task/evaluator instance is not yet frozen and no scientific run has been executed.

```text
synthetic smoke recovery
↛ real-agent causal evidence
```

### Null claim boundary

If:

```text
E-aligned ≈ E-misaligned
```

then the authorized conclusion is local:

> **Correct semantic assignment of development evidence adds no detectable value under the tested mutation surface, task family, resource envelope, and measurement resolution.**

A null does not authorize post-hoc rescue by a new `Z`, wider mutation surface, greater autonomy, or a claim that the effect must emerge at scale.

## Authority separation

Keep explicit:

```text
predictive
≠ causal

causal
≠ mechanism

mechanism
≠ construct identity

replication
≠ transport

transport
≠ universal law
```

Likewise:

```text
A_leave ↛ A_adopt
```

Evidence sufficient to withdraw authority from an incumbent claim does not automatically grant authority to a proposed replacement.

## Governing rule

> **Construct the strongest ordinary explanation first. Measure where it fails. Strengthen the ordinary explanation. Replicate the remaining discrepancy. Introduce new scientific structure only if the residual survives.**
