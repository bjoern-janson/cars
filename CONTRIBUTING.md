# Contributing

Contributions are welcome when they increase discriminative evaluation quality rather than merely expand the framework.

High-value contributions include:

- independently authored adversarial cases;
- counterexamples where CARS makes reasoning worse;
- length-matched control prompts;
- blinded scoring procedures;
- cross-model replications;
- alternative explanations for observed effects;
- cost measurements;
- ablation studies.

Please keep prompt versions immutable after evaluation results are known. Proposed prompt changes should create a new version rather than overwrite historical interventions.
